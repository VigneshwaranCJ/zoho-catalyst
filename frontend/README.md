# Frontend: admin dashboard

Next.js 16 (App Router) + React 19 + Tailwind CSS 4 + shadcn/ui.

```powershell
npm install
npm run dev   # http://localhost:3000 (expects the API on http://127.0.0.1:8000)
```

- `/api/*` is proxied to FastAPI by `next.config.ts` (`BACKEND_INTERNAL_URL`), so auth cookies are first-party.
- `proxy.ts` (Next 16's new name for middleware) only does an optimistic redirect to `/login`; real authorization happens in the API.
- `AGENTS.md` is generated by `next dev`; keep it committed.

See the root README for full setup.
